## 演習ラボ 0502: Entra ID のユーザー アカウントに対するセルフサービス パスワード リセットの構成

### 概要

このラボでは、Entra ID のユーザー アカウントに対してセルフサービス パスワード リセット (SSPR) を構成し、検証します。

#### 前提条件

このラボの前に、次のラボを完了しておく必要があります。

- 0102-Synchronizing identities by using Entra Connect
- 0203-Manage Device Enrollment into Intune

#### シナリオ

ヘルプ デスクによると、多数のサポート チケットがパスワードのリセットに関連しています。ユーザーが自分でパスワードをリセットできるソリューションを提案するよう依頼されました。AD DS から同期されているアカウントについては、Entra ID と AD DS の両方のパスワードがリセットされるようにする必要があります。

#### タスク 1: パスワード ライトバックの構成

1. **SEA-SVR1** に **Contoso\Administrator** としてパスワード **Pa55w.rd** を使用してサインインし、**Server Manager** を閉じます。

2. デスクトップの **Azure AD Connect** をダブルクリックします。

3. **Welcome to Microsoft Entra Connect Sync** ページで **Configure** を選択します。

4. **Additional tasks** ページで **Customize synchronization options**、**Next** の順に選択します。

5. **Connect to Microsoft Entra ID** ページで、必要に応じて **USERNAME** テキスト ボックスに **admin@yourtenant.onmicrosoft.com** と入力し、**Next** を選択します。

6. **Sign in to your account** ダイアログで管理者アカウントを選択し、テナント管理者のパスワードを入力して **Sign in** を選択します。

7. **Connect to your directories** ページで **Next** を選択します。

8. **Domain and OU filtering** ページで **Next** を選択します。

9. **Optional features** ページで **Password writeback** を選択し、**Next** を選択します。

10. **Ready to configure** ページで **Configure** を選択します。

11. **Configuration complete** ページで **Exit** を選択します。

#### タスク 2: セルフサービス パスワード リセットの有効化

1. 手元 PC で Microsoft Edge を開き、[**https://entra.microsoft.com/**](https://entra.microsoft.com/) にアクセスします。

2. **Admin@yourtenant.onmicrosoft.com** とテナント管理者のパスワードを使用してサインインします。**サインインの状態を維持しますか?** と表示されたら、**いいえ**を選択します。

   Microsoft Entra 管理センターが開きます。

3. ナビゲーション ペインの **Entra ID** で、**認証方法**を選択します。

4. **SMS** と **Email OTP** の**有効**列 (3 列目) に**はい**と表示されていることを確認します。

5. ナビゲーション ペインの **Entra ID** で、**パスワード リセット**を選択します。

6. **パスワード リセット | プロパティ**ウィンドウで、すべてのユーザーにセルフサービス パスワード リセットを有効にするために**すべて**を選択し、**保存**を選択します。

7. **パスワード リセット | プロパティ**ウィンドウで、**認証方法**を選択し、**セキュリティの質問**チェック ボックスをオンにします。

8. **登録に必要な質問の数**で **3** を選択します。

9. **リセットに必要な質問の数**で **3** を選択します。

10. **セキュリティの質問の選択**セクションで、**セキュリティの質問が構成されていません**、**定義済み**の順に選択します。任意の質問を 3 つ選択し、**OK** を 2 回選択します。

11. **保存**を選択します。

12. **登録**を選択します。

13. **登録**ページで、**サインイン時にユーザーに登録を要求しますか?** が**いいえ**に設定されていることを確認し、**保存**を選択します。

14. ナビゲーション ペインで、**オンプレミスの統合**を選択します。

15. オンプレミスのライトバック クライアントが実行中であることを確認します。

16. Microsoft Edge を閉じます。

#### タスク 3: セルフサービス パスワード リセットの検証

1. **SEA-WS3** に切り替えます。

2. 必要に応じて、**Admin** としてパスワード **Pa55w.rd** を使用してサインインします。

3. タスク バーで **Microsoft Edge** を選択します。

4. [**https://myaccount.microsoft.com**](https://myaccount.microsoft.com) にアクセスします。

5. **アカウントの選択**ページで、**別のアカウントを使用する**を選択します。

6. **サインイン**ページで **Aaron@yourtenant.onmicrosoft.com** と入力し、**次へ**を選択します。

   **注**: Alex ではなく Aaron としてサインインしてください。

7. **パスワードの入力**ページで **Pa55w.rd** と入力し、**サインイン**を選択します。Microsoft Edge にパスワードの保存を求められたら、**保存**を選択します。

8. **マイ アカウント**ページのナビゲーション ペインで、**パスワードの変更**を選択します。

9. **本人確認**ページで、**次へ**を選択します。

10. **コードの入力**ページで、SMS で受信した確認コードを入力します。

11. **アカウントを保護する**ダイアログが表示された場合は、**今はスキップ (残り _x_ 回)**を選択します。

12. **サインインの状態を維持しますか?** と表示された場合は、**いいえ**を選択します。

13. **パスワードの変更**ページで次の情報を入力し、**送信**を選択します。

    - 古いパスワード: **Pa55w.rd**
    - 新しいパスワード: **Pa55w.rd1234\!**
    - 新しいパスワードの確認: **Pa55w.rd1234\!**

14. Microsoft Edge にパスワードの保存を求められたら、**保存**を選択します。

15. **成功しました。パスワードが変更されました**ダイアログで、**完了**を選択します。

16. Microsoft Edge を閉じ、SEA-WS3 からサインアウトします。

#### タスク 4: AD 同期の実行

_注: 通常、パスワード ライトバックにこの手順は必要ありませんが、ラボ環境固有の問題に対処し、AD DS が Entra ID と同期されるようにするために実行することをお勧めします。_

1. **SEA-SVR1** に切り替えます。

2. **Start** を右クリックし、**Windows PowerShell (Admin)** を選択します。

3. **Windows PowerShell** のコマンド プロンプトで次のコマンドを入力し、**Enter** キーを押します。`Start-ADSyncSyncCycle â€“PolicyType Delta`

4. Windows PowerShell を閉じ、約 3 ～ 4 分待ちます。

#### タスク 5: パスワード ライトバックの確認

1. **SEA-CL1** に切り替え、必要に応じてサインアウトします。

2. **SEA-CL1** で **Other user** を選択し、**Contoso\Aaron** としてパスワード **Pa55w.rd** を使用してサインインを試みます。

3. ユーザー名またはパスワードが正しくないことを示すメッセージが表示されることを確認します。

4. **SEA-CL1** に **Contoso\Aaron** としてパスワード **Pa55w.rd1234\!** を使用してサインインします。

   サインインできることを確認します。これにより、MyAccount ポータルで変更したパスワードがローカルの Active Directory Domain Services (AD DS) アカウントへライトバックされたことが確認できます。

5. **SEA-CL1** からサインアウトします。

**結果**: この演習を完了すると、セルフサービス パスワード リセットが正常に構成および検証されます。

**ラボ終了**
