# 演習ラボ 0201: Entra 参加の構成と管理

## 概要

このラボでは、Entra ID 参加の設定を構成し、Windows デバイスで標準の Entra 参加と Entra ハイブリッド参加の両方を実行します。

### 前提条件

このラボを開始する前に、次のラボを完了しておく必要があります。

- 0102-Synchronizing Identities by using Microsoft Entra Connect

  > 注: Entra ID への Windows Hello サインイン認証を保護するために使用するテキスト メッセージを受信できる携帯電話も必要です。

## 演習 1: Entra 参加の構成

### シナリオ

すべてのユーザーがデバイスを Entra ID に参加させられるように、Entra ID のデバイス設定を構成します。また、ユーザーが参加させられるデバイスを最大20台に制限し、Allan Deyoung をすべての Entra 参加済みデバイスのローカル管理者として追加します。最後に、Joni Sherman が SEA-WS1 をテナントへ参加させ、Entra 参加が想定どおりに機能することを確認します。

### タスク 1: Entra 参加のデバイス設定を構成する

1. On **SEA-SVR1**, if necessary, sign in as **Contoso\\Administrator** with the password of **Pa55w.rd** and close Server Manager。

2. タスク バーで **Microsoft Edge**, in the address bar **https://entra.microsoft.com**, and then press **Enter**。

2. Sign in as user `Admin@yourtenant.onmicrosoft.com`, and use the tenant Admin password. If the **Stay signed in?** prompt appears, **いいえ**。

   > The Microsoft Entra admin center opens.

2. Microsoft Entra 管理センターのナビゲーション ペインで **デバイス**, を選択し、続いて **すべてのデバイス**。

   > 次を確認します: there are no devices found, as you have not joined any devices yet.

2. **Devices | All devices**ページで **Device settings**を選択します。

2. 次の画面で **Devices|Device settings** ページ, in the details ペイン, under **Users may join devices to Microsoft Entra**, verify that **All** is selected。

   > This indicates that all Entra users are permitted to join Windows 10 or newer devices to Microsoft Entra. 次を確認します: this setting does not apply to Entra hybrid  joined devices, or devices joined by using Windows Autopilot self-deployment mode.

2. 次の画面で **Require Multi-factor Authentication to register or join devices with Microsoft Entra** セクション, verify that the setting is set to **いいえ**。

2. 次の画面で **Maximum number of devices per user** セクション, **20**。

2. 次の項目で **Local administrator settings**, **Manage Additional local administrators on all Entra joined devices**. The Device Administrators ページ opens。

2. 次の画面で Device Administrators ページ, **+ Add assignments**。

2. 次の画面で Search ボックス, **Allan Deyoung**, select the **Allan Deyoung** user object, を選択し、続いて **Add**。

    > Allan Deyoung will now be added as a Device Administrator on all Entra joined devices.

2. 次の画面で navigation breadcrumbs, select the **Devices | Device settings** リンク at the top of the ページ。

2. 次の画面で Device settings ページ, **Save**。

2. 次の画面で Entra admin center, in the navigation ペイン, **Authentication methods**。

2. **Authentication methods**ページで **SMS**を選択します。

2. 次の画面で **SMS settings** ページ, **Enable** (to make SMS available as an authenticatiom method)。

2. ページ下部で **Save**。

### タスク 2: Entra 参加を実行する

1. **SEA-WS1** and sign in as **Admin** with the password of **Pa55w.rd** に切り替えます。

2. タスク バーで **Start** を選択し、続いて **Settings**。

3. **Settings**ウィンドウで **Accounts**を選択します。

4. 次の画面で Accounts ページ, **Access work or school**。

5. **Access work or school**ページで **Connect**を選択します。

6. **Microsoft account**ウィンドウで **Join this device to Microsoft Entra ID**を選択します。

7. **Sign in**ページで **JoniS@yourtenant.onmicrosoft.com** を選択し、続いて **Next**を選択します。

8. 次の画面で **Enter password** ページ, enter the user password (from the Resources タブ) を選択し、続いて **Sign in**。

9. **Make sure this is your organization**ダイアログで **Join**を選択します。

10. **You're all set!**ページで **Done**を選択します。

11. 次の画面で **Access work or school** ページ, verify that **Connected to Contoso's Azure AD** is displayed。

12. **Settings** を閉じます。

### タスク 3: Entra 参加を検証する

1. On SEA-WS1, right-click **Start**, を選択し、続いて **Windows Terminal**。

2. 次の画面で PowerShell console, type the following and press **Enter**:

   ```powershell
   dsregcmd /status
   ```

3. **Device State** の出力に **AzureAdJoined : YES** と表示されていることを確認します。

   > This indicates that the device is Entra joined.

4. PowerShell を閉じます。

5. **Start** を右クリックし、**Computer Management** を選択します。

6. In Computer Management, expand **Local Users and Groups**, を選択し、続いて **Groups**。

7. Double-click the **Administrators** group。

   > Joni Sherman が SEA-WS1 のローカル管理者として追加されていることを確認します。また、セキュリティ識別子（SID）で表された2つのセキュリティ プリンシパルを確認します。これらの SID は、Entra ID のグローバル管理者ロールと Entra 参加済みデバイスの管理者ロールを表します。 

8. SEA-WS1 で開いているすべてのウィンドウを閉じます。

9. **SEA-SVR1** に切り替えます。

10. In Microsoft Edge, in the Microsoft Entra admin center, **デバイス**, を選択し、続いて **すべてのデバイス**。

    > 次の画面で Devices ペイン, notice that SEA-WS1 is listed. 

11. 次を確認します: the **参加の種類** is listed as **Microsoft Entra joined** and that the owner is **Joni Sherman**。

    > Also note that the MDM 列 shows None. This indicates that this device is not yet managed by Microsoft Intune.

### タスク 4: Entra ユーザーとして Windows にサインインする

1. Switch to **SEA-WS1** and then sign in as **`JoniS@yourtenant.onmicrosoft.com`** with the user password you used in the previous task。

2. At the **Use Windows Hello with your account** ページ, **OK**。

3. **Let's keep your account secure**ページで **Next**を選択します。

4. 次の画面で **Install Microsoft Authenticator** ページ, **Set up a different way to sign in**. **Note** Ensure you select the correct リンク。

5. **Add a sign-in method**ダイアログで **Phone**を選択します。

6. 次の画面で **Add your phone number** ページ, select your **Country code** and in the **Phone number** フィールド, enter your mobile phone number which is able to receive text messages, 続いて **Next**。

7. When you receive the verification code, enter the code on the **Verify your phone number** ページ を選択し、続いて **Next**。

8. **Phone number added**ページで **Done**を選択します。

9. 次の画面で **Set up a PIN** ページ, in the **New PIN** and **Confirm PIN** boxes, **`102938`** を選択し、続いて **OK**。

10. **All set!**ページで **OK**を選択します。

### タスク 5: Entra から Windows デバイスを削除する

1. On SEA-WS1, whilst still signed in as **Joni Sherman**, **Start** を選択し、続いて **Settings**。

2. **Settings**ウィンドウで **Accounts**を選択します。

3. 次の画面で Accounts ページ, **Access work or school**。

4. **Access work or school**ページで **Connected to Contoso's Azure AD**を選択します。

5. **Disconnect** and then select **Yes** を選択します。

6. **Disconnect from the organization**ページで **Disconnect**を選択します。

7. 次の画面で **Windows Security** ダイアログ, in the **Email address** ボックス, **Admin** and in the **Password** ボックス, **Pa55w.rd**. Select **OK**。

8. 次の画面で **Restart your PC** ダイアログ, **Restart now**. SEA-WS1 restarts。

**結果**: この演習を完了すると、Microsoft Entra のデバイス設定を構成し、デバイスを Entra に参加させた後、Entra から削除できます。

## 演習 2: Entra ハイブリッド参加の構成

### シナリオ

一部の Contoso Windows デバイスは、現在ローカルの Active Directory Domain Services に参加しています。クラウド サービスへシームレスにアクセスできるように、Entra ハイブリッド参加を有効にします。Entra Connect Sync を再構成し、SEA-CL2 で処理をテストします。

### タスク 1: 環境を準備する

1. **SEA-SVR1** に切り替えます。

2. **Start**, expand **Windows Administrative Tools**, and then select **Active Directory Users and Computers** を選択します。

3. In **Active Directory Users and Computers**, right-click **Contoso.com**, point to **New**, を選択し、続いて **Organizational Unit**。

4. **New-Object - Organizational Unit**ダイアログで **`Entra ID clients`** を選択し、続いて **OK**を選択します。

5. ナビゲーション ペインで **Seattle Clients**。

6. **SEA-CL2** を右クリックし、**Move** を選択します。

7. **Move**ダイアログで **Entra ID clients** を選択し、続いて **OK**を選択します。

8. **Active Directory Users and Computers** を閉じます。

### タスク 2: Entra Connect Sync で Entra ハイブリッド参加を構成する

1. **SEA-SVR1** の **Desktop** で **Azure AD Connect** をダブルクリックします。

2. **Microsoft Entra Connect Sync** ウィンドウで **Configure** を選択します。

3. **Additional tasks**ページで **Configure device options** and **Next**を選択します。

4. **Overview**ページで **Next**を選択します。

5. **Connect to Microsoft Entra ID**ページで **Next**を選択します。

6. 次の画面で **Sign in to your account** ウィンドウ, select the tenant admin account, and then enter the tenant password and **Sign in**。

7. **Device options**ページで **Configure Hybrid Microsoft Entra ID join**, を選択し、続いて **Next**を選択します。

8. **Device operating systems**ページで **Windows 10 or later domain-joined devices**, を選択し、続いて **Next**を選択します。

9. **SCP configuration** ページで **Contoso.com** の横にあるチェック ボックスをオンにします。

10. **Authentication Service** ドロップダウンから **Microsoft Entra ID** を選択し、**Add** を選択します。

11. **Enterprise Admin Credentials** ウィンドウで、**User name** に **Contoso\\Administrator**、**Password** に **Pa55w.rd** と入力します。**OK**、**Next** の順に選択します。

12. **Ready to configure** ページで **Configure** を選択して構成を実行します。

13. 構成が完了したら、 **Exit**。

14. **SEA-CL2** に切り替えます。

15. サインイン ページで **Power** ボタンを選択し、**Restart** を選択します。

    > **注**: **SEA-CL2** を再起動すると、Entra Connect Sync の再構成によって作成された SCP がより早く検出されるようになります。

16. **SEA-CL2** の再起動後、パスワード **Pa55w.rd** を使用して **Contoso\\Administrator** としてサインインします。

### タスク 3: 新しい OU を同期するよう Entra Connect Sync を再構成する

1. **SEA-SVR1** の **Desktop** で **Azure AD Connect** をダブルクリックします。

2. **Microsoft Entra Connect Sync** ウィンドウで **Configure** を選択します。

3. **Additional tasks** ページで **Customize synchronization options**、**Next** の順に選択します。

4. **Connect to Microsoft Entra ID** ページで **Next** を選択します。

5. **Sign in to your account** ウィンドウでテナント管理者アカウントを選択し、テナント パスワードを入力して **Sign in** を選択します。

6. **Connect your directories** ページで **Next** を選択します。

7. **Domain and OU filtering** ページで **Sync selected domains and OUs** が選択されていることを確認し、**Contoso.com** を展開します。

8. **Entra ID clients** の横にあるチェック ボックスをオンにします。ほかの変更は行わず、**Next** を選択します。

9. **Optional features** ページでは変更を行わず、**Next** を選択します。

10. **Ready to configure** ウィンドウで **Configure** を選択し、構成を実行して同期を開始します。

11. 構成が完了したら、**Exit** を選択します。

    > **注**: 同期対象の OU を変更すると、Entra Connect Sync によって自動的に同期が実行されます。同期状態は **Synchronization Service** を使用して監視できます。

### タスク 4: Entra ハイブリッド参加を確認する

1. **SEA-CL2** に切り替えます。

2. **Start** を右クリックし、**Shut down or sign out**、**Restart** の順に選択します。

    _注: 再起動すると、SEA-CL2 で Entra ハイブリッド参加が開始されます。_
   
3. **SEA-CL2** の再起動後、パスワード **Pa55w.rd** を使用して **Contoso\\Administrator** としてサインインします。
    
4. タスク バーで **Start** を右クリックし、**Windows Terminal (Admin)** を選択します。

5. PowerShell ウィンドウで次のコマンドを入力し、**Enter** キーを押します。

   ```powershell
   dsregcmd /status
   ```

6. **Device State** の出力に **AzureAdJoined : YES** と **DomainJoined : YES** が表示されていることを確認します。

   > **注**: デバイスがまだ Entra ID に参加していない場合は、**SEA-SRV1** に切り替えて次のコマンドを実行します。完了後、SEA-CL2 に戻り、コンピューターをもう一度再起動します。
   
   ```powershell
   Start-ADSyncSyncCycle -PolicyType Delta
   ```

7. SEA-CL2 で開いているすべてのウィンドウを閉じ、サインアウトします。

8. 手元の PC の Microsoft Entra 管理センターに切り替えます。

9. **デバイス**、**すべてのデバイス**の順に選択します。

10. **SEA-CL2** の **参加の種類**の値が **Microsoft Entra hybrid joined** であることを確認します。SEA-CL2 が一覧にない場合は、必要に応じて **更新**ボタンを選択します。

11. 手元の PC で開いている Microsoft Edge のウィンドウを閉じます。

**結果**: この演習を完了すると、Entra ハイブリッド参加の構成と検証が完了します。

**ラボ終了**
