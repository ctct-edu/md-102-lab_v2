## 演習ラボ 0203: Intune へのデバイス登録の管理

### 概要

この演習では、ライセンスの確認と割り当て、Windows の自動登録の構成、および登録制限の構成を行い、Microsoft Intune を使用したデバイス管理の準備を行います。

#### 前提条件

このラボを実施する前に、次のラボを完了しておく必要があります。
- 0101-Managing Identities in Entra ID
- 0102-Synchronizing identities by using Entra Connect<br>注: Entra ID への Windows Hello サインイン認証を保護するために使用するテキスト メッセージを受信できる携帯電話も必要になります。

#### シナリオ

Microsoft Intune を使用したデバイス管理の準備を行う必要があります。まず、デバイス管理に適したライセンスがユーザーに割り当てられていることを確認する必要があります。検証テストとして、Aaron Nicholls に必要なライセンスを割り当てます。また、Entra ID に参加または登録された Windows デバイスが、自動的に Intune に登録されるようにする必要があります。さらに、Sales グループのメンバーが個人所有の Android デバイスを Intune に登録できないように制限し、登録デバイス数の上限を 10 台に引き上げるよう依頼されています。最後に、Allan Deyoung をデバイス登録マネージャーとして構成し、1000 台のデバイスを登録できるようにする必要があります。

#### タスク 1: デバイス管理用のライセンスを確認して割り当てる
1. 手元 PC で、日本語版 Microsoft Edge を起動します。アドレス バーに [**https://admin.microsoft.com**](https://admin.microsoft.com) と入力し、**Enter** キーを押します。
2. **Admin@yourtenant.onmicrosoft.com** としてサインインし、テナントの管理者パスワードを使用します。**サインインの状態を維持しますか?** のメッセージが表示された場合は、**いいえ** を選択します。<br>Microsoft 365 管理センターが開きます。
3. Microsoft 365 管理センターのナビゲーション ペインで、**ユーザー** > **アクティブなユーザー** を選択します。
4. **Aaron Nicholls** を選択します (チェック ボックスではなく、名前を選択します)。
5. **ライセンスとアプリ** タブを選択します。
6. **場所の選択** フィールドが未入力の場合は、ドロップダウン リストから場所を選択します。
7. **Enterprise Mobility + Security E5** と **Office 365 E5 (no Teams)** の横にあるチェック ボックスをオンにします。
8. **変更の保存** を選択します。
9. 変更が保存されたら、Edge の **Microsoft 365 管理センター** タブを閉じます。

#### タスク 2: Microsoft Intune への Windows 自動登録を有効にする
1. 手元 PC の Microsoft Edge で新しいタブを開き、アドレス バーに [**https://intune.microsoft.com**](https://intune.microsoft.com) と入力し、続いて **Enter** キーを押します。<br>Microsoft Intune 管理センターが開きます。
2. Microsoft Intune 管理センターで、**デバイス** を選択します。
3. デバイス ペインの **デバイスのオンボード** セクションで、**登録** を選択します。
4. デバイスの登録ペインで、**Windows** が選択されていることを確認します。
5. **登録オプション** セクションで、**自動登録** を選択します。
6. **MDM ユーザー スコープ** 行で **すべて** を選択し、続いて **保存** を選択します。<br>_**注**: この手順を実行することで、Windows デバイスから Entra 参加または Entra 登録を行うすべてのユーザーに対して、Intune への自動登録を有効にしました。_

#### タスク 3: 登録制限を構成する
1. Microsoft Intune 管理センターで、**デバイス** を選択します。
2. デバイス ペインの **デバイスのオンボード** セクションで、**登録** を選択します。
3. **デバイス | 登録** ページの **登録オプション** セクションで、登録デバイス数の上限とプラットフォームの制限を作成できることに注目します。
4. **デバイス プラットフォームの制限** を選択します。<br>**すべてのユーザー** に割り当てられた既定のデバイスの種類の制限があることに注目します。この既定の制限では、すべてのデバイスの種類が許可されています。
5. 詳細ペインで **Android の制限** タブを選択し、続いて **+ 制限の作成** を選択します。
6. 制限の作成ページの名前ボックスに **Android Personal Device Restriction** と入力します。**次へ** を選択します。
7. プラットフォームの設定ページの **個人所有** で、次のデバイスの種類に対して **ブロック** を選択します。
    - Android Enterprise (仕事用プロファイル)
    - Android デバイス管理者
8. プラットフォームの設定ページで、**次へ** を選択します。
9. スコープ タグ ページで、**次へ** を選択します。
10. 割り当てページの **包含されたグループ** で、**グループの追加** を選択します。
11. **Sales** を検索して選択し、続いて **選択** をクリックして、**次へ** をクリックします。
12. **確認と作成** ページで、**作成** を選択します。<br>Android Personal Device Restriction が優先度 1 で割り当てられていることに注目します。
13. パンくずナビゲーションで、**デバイス | 登録** を選択します。
14. **登録オプション** セクションで、**デバイス数の制限** を選択します。<br>**すべてのユーザー** に割り当てられた既定のデバイス数の制限があることに注目します。この既定の制限では、ユーザーあたりの登録デバイス数の上限が 5 台に設定されています。
15. 詳細ペインで、**+ 制限の作成** を選択します。
16. 制限の作成ページの名前ボックスに **Sales Device Enrollment Limit** と入力します。**次へ** を選択します。
17. デバイス数の上限ページで **10** を選択し、続いて **次へ** を選択します。
18. スコープ タグ ページで、**次へ** を選択します。
19. 割り当てページの **包含されたグループ** で、**グループの追加** を選択します。
20. **Sales** を検索して選択し、続いて **選択** をクリックして、**次へ** をクリックします。
21. **確認と作成** ページで、**作成** を選択します。<br>Sales Device Enrollment Limit が、デバイス数の上限 10 で構成され、優先度 1 で割り当てられていることに注目します。

#### タスク 4: デバイス登録マネージャーを構成する
1. Microsoft Intune 管理センターで、**デバイス** を選択します。
2. デバイス ペインで、**登録** を選択します。
3. デバイスの登録ペインで、**デバイス登録マネージャー** を選択します。<br>既定では、デバイス登録マネージャーが構成されていないことに注目します。
4. **デバイス | デバイス登録マネージャー** ページで、**+ 追加** を選択します。
5. **ユーザーの追加** ページのユーザー名に **AllanD@yourtenant.onmicrosoft.com** を入力し、続いて **追加** を選択します。<br>これで、Allan は最大 1000 台のデバイスを登録できるようになりました。
6. Microsoft Intune 管理センターのナビゲーション ペインで、**ホーム** を選択します。
7. Microsoft Edge を閉じます。  
**結果**: この演習を完了すると、ライセンスの確認と割り当て、Windows の自動登録の構成、登録制限の有効化と割り当て、およびデバイス登録マネージャーの構成に成功したことになります。  
**ラボの終了**
