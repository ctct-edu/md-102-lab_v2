# 演習ラボ 0201: Entra Join の構成と管理

## 概要

このラボでは、Entra ID 参加の設定を構成し、Windows デバイスで標準の Entra 参加と Entra ハイブリッド参加の両方を実行します。

### 前提条件

このラボを開始する前に、次のラボを完了しておく必要があります。

- 0102-Synchronizing Identities by using Microsoft Entra Connect

  > 注: You will also need a mobile phone that can receive text messages used to secure Windows Hello sign in authentication to Entra ID.

## 演習 1: Entra Join の構成

### シナリオ

You need to configure Entra ID device settings to ensure that all users are allowed to join devices to Entra ID. You also need to ensure that users can only join a maximum of 20 devices and that Allan Deyoung is added as a local administrator on all Entra joined devices. Finally, you will 次を確認します: Entra join works as expected by having Joni Sherman join SEA-WS1 to the tenant.

### タスク 1: Entra 参加のデバイス設定を構成する

1. On **SEA-SVR1**, if necessary, 次のユーザーとしてサインインします: **Contoso\\Administrator** パスワード of **Pa55w.rd** and close Server Manager.

2. タスク バーで 選択します **Microsoft Edge**, アドレス バーに type **https://entra.microsoft.com**, 続いて **Enter** キーを押します.

3. Sign in as user `Admin@yourtenant.onmicrosoft.com`, and use the tenant Admin password. If the **Stay signed in?** prompt appears, 選択します **No**. 

   > The Microsoft Entra admin center opens.

4. Microsoft Entra 管理センターで, in the navigation pane, 選択します **Devices**, and then 選択します **All devices**.

   > 次の点を確認します: there are no devices found, as you have not joined any devices yet.

5. On the **Devices | All devices** page, 選択します **Device settings**.

6. On the **Devices|Device settings** page, in the details pane, under **Users may join devices to Microsoft Entra**, 次を確認します: **All** is 選択しますed. 

   > これは次を示します: all Entra users are permitted to join Windows 10 or newer devices to Microsoft Entra. Note that this setting does not apply to Entra hybrid  joined devices, or devices joined by using Windows Autopilot self-deployment mode.

7. In the **Require Multi-factor Authentication to register or join devices with Microsoft Entra** section, 次を確認します: the setting is set to **No**. 

8. In the **Maximum number of devices per user** section, 選択します **20**.

9. Under **Local administrator settings**, 選択します **Manage Additional local administrators on all Entra joined devices**. The Device Administrators page opens.

10. In the Device Administrators page, 選択します **+ Add assignments**.

11. In the Search box, enter **Allan Deyoung**, 選択します the **Allan Deyoung** user object, and then 選択します **Add**. 

    > Allan Deyoung will now be added as a Device Administrator on all Entra joined devices.

12. In the navigation breadcrumbs, 選択します the **Devices | Device settings** link at the top of the page.

13. On the Device settings page, 選択します **Save**.

14. In the Entra admin center, in the navigation pane, 選択します **Authentication methods**.

15. In the **Authentication methods** page, 選択します **SMS**.

16. In the **SMS settings** page, 選択します **Enable** (to make SMS available as an authenticatiom method).

17. At the bottom of the page, 選択します **Save**.

### タスク 2: Entra 参加を実行する

1. Switch to **SEA-WS1** and 次のユーザーとしてサインインします: **Admin** パスワード of **Pa55w.rd**.

2. タスク バーで, 選択します **Start** and then 選択します **Settings**.

3. In the **Settings** window, 選択します **Accounts**.

4. On the Accounts page, 選択します **Access work or school**.

5. In the **Access work or school** page, 選択します **Connect**.

6. In the **Microsoft account** window, 選択します **Join this device to Microsoft Entra ID**.

7. On the **Sign in** page, type **JoniS@yourtenant.onmicrosoft.com** and then 選択します **Next**.

8. On the **Enter password** page, enter the user password (from the Resources tab) and then 選択します **Sign in**.

9. On the **Make sure this is your organization** dialog box, 選択します **Join**.

10. On the **You're all set!** page, 選択します **Done**.

11. On the **Access work or school** page, 次を確認します: **Connected to Contoso's Azure AD** 表示されていること.

12. Close the **Settings** page.

### タスク 3: Entra 参加を検証する

1. On SEA-WS1, right-click **Start**, and then 選択します **Windows Terminal**.

2. In the PowerShell console, 次を入力します and press **Enter**:

   ```powershell
   dsregcmd /status
   ```

3. In the output under **Device State**, 次を確認します: **AzureAdJoined : YES** 表示されていること.

   > これは次を示します: the device is Entra joined.

4. Close PowerShell.

5. Right-click **Start** and then 選択します **Computer Management**.

6. In Computer Management, expand **Local Users and Groups**, and then 選択します **Groups**.

7. Double-click the **Administrators** group.

   > 次の点を確認します: Joni Sherman has been added as a local Administrator on SEA-WS1. Also notice two security principals represented by their security identifiers (SID). These two SIDs represent the Entra ID global administrator role, and the Entra joined device administrator role. 

8. 開いているすべてのウィンドウを閉じます and サインアウトします of SEA-WS1.

9. Switch to **SEA-SVR1**.

10. In Microsoft Edge, in the Microsoft Entra admin center, 選択します **Devices**, and then 選択します **All devices**. 

    > In the Devices pane, notice that SEA-WS1 一覧に表示されていること. 

11. Verify that the **Join Type** 一覧に表示されていること as **Microsoft Entra joined** and that the owner is **Joni Sherman**. 

    > Also note that the MDM column shows None. これは次を示します: this device is not yet managed by Microsoft Intune.

### タスク 4: Entra ユーザーとして Windows にサインインする

1. Switch to **SEA-WS1** and then 次のユーザーとしてサインインします: **`JoniS@yourtenant.onmicrosoft.com`** with the user password you used in the previous task. 

2. At the **Use Windows Hello with your account** page, 選択します **OK**.

3. On the **Let's keep your account secure** page, 選択します **Next**.

4. On the **Install Microsoft Authenticator** page, 選択します **Set up a different way to sign in**. **Note** Ensure you 選択します the correct link.

5. On the **Add a sign-in method** dialog box, 選択します **Phone**.

6. On the **Add your phone number** page, 選択します your **Country code** and in the **Phone number** field, enter your mobile phone number which is able to receive text messages, then 選択します **Next**.

7. When you receive the verification code, enter the code on the **Verify your phone number** page and then 選択します **Next**.

8. On the **Phone number added** page, 選択します **Done**.

9. On the **Set up a PIN** page, in the **New PIN** and **Confirm PIN** boxes, type **`102938`** and then 選択します **OK**.

10. On the **All set!** page, 選択します **OK**.

### タスク 5: Entra から Windows デバイスを削除する

1. On SEA-WS1, whilst still signed in as **Joni Sherman**, 選択します **Start** and then 選択します **Settings**.

2. In the **Settings** window, 選択します **Accounts**.

3. On the Accounts page, 選択します **Access work or school**.

4. In the **Access work or school** page, 選択します **Connected to Contoso's Azure AD**.

5. Select **Disconnect** and then 選択します **Yes**.

6. On the **Disconnect from the organization** page, 選択します **Disconnect**.

7. On the **Windows Security** dialog box, in the **Email address** box, enter **Admin** and in the **Password** box, type **Pa55w.rd**. Select **OK**.

8. In the **Restart your PC** dialog box, 選択します **Restart now**. SEA-WS1 restarts.

**結果**: After completing this exercise, you will have configured Microsoft Entra device settings, joined a device to Entra, and removed a device from Entra.

## 演習 2: Entra ハイブリッド参加の構成

### シナリオ

Some Contoso Windows devices are currently joined to the local Active Directory Domain Services. To enable those devices to seamlessly access cloud services you plan to enable Entra hybrid join. You will test Entra hybrid join by re-configuring Entra Connect sync and testing out the process on SEA-CL2.

### タスク 1: 環境を準備する

1. Switch to **SEA-SVR1**.

2. Select **Start**, expand **Windows Administrative Tools**, and then 選択します **Active Directory Users and Computers**.

3. In **Active Directory Users and Computers**, right-click **Contoso.com**, point to **New**, and then 選択します **Organizational Unit**.

4. In the **New-Object - Organizational Unit** dialog box, type **`Entra ID clients`** and then 選択します **OK**.

5. In the navigation pane, 選択します **Seattle Clients**.

6. Right-click **SEA-CL2** and then 選択します **Move**.

7. In the **Move** dialog box, 選択します **Entra ID clients** and then 選択します **OK**.

8. Close **Active Directory Users and Computers**.

### タスク 2: Entra Connect Sync で Entra ハイブリッド参加を構成する

1. On **SEA-SVR1**, on the **Desktop**, double-click **Azure AD Connect**.

2. In the **Microsoft Entra Connect Sync** window 選択します **Configure**.

3. On the **Additional tasks** page, 選択します **Configure device options** and 選択します **Next**.

4. On the **Overview** page, 選択します **Next**.

5. On the **Connect to Microsoft Entra ID** page, 選択します **Next**.

6. On the **Sign in to your account** window, 選択します the tenant admin account, and then enter the tenant password and 選択します **Sign in**.

7. On the **Device options** page, 選択します **Configure Hybrid Microsoft Entra ID join**, and then 選択します **Next**.

8. On the **Device operating systems** page, 選択します **Windows 10 or later domain-joined devices**, and then 選択します **Next**.

9. On the **SCP configuration** page, 選択します the check box next to **Contoso.com**. 

10. Select **Microsoft Entra ID** from the **Authentication Service** dropdown and 選択します **Add**. 

11. In the **Enterprise Admin Credentials** window enter **Contoso\\Administrator** as **User name** and **Pa55w.rd** as **Password**. Select **OK** and 選択します **Next**.

12. In the **Ready to configure** page, 選択します **Configure** to run the configuration.

13. When the configuration is complete, 選択します **Exit**.

14. Switch to **SEA-CL2**.

15. At the sign-in page, 選択します the **Power** button and then 選択します **Restart**.

    > **Note** Restarting **SEA-CL2** will enable quicker discovery of the SCP created by reconfiguring Entra Connect Sync.

16. After **SEA-CL2** has restarted, 次のユーザーとしてサインインします: **Contoso\\Administrator** パスワード of **Pa55w.rd**.

### タスク 3: 新しい OU を同期するよう Entra Connect Sync を再構成する

1. On **SEA-SVR1**, on the **Desktop**, double-click **Azure AD Connect**.

2. In the **Microsoft Entra Connect Sync** window 選択します **Configure**.

3. On the **Additional tasks** page, 選択します **Customize synchronization options** and 選択します **Next**.

4. On the **Connect to Microsoft Entra ID** page, 選択します **Next**.

5. One the **Sign in to your account** window, 選択します the tenant admin account, and then enter the tenant password and 選択します **Sign in**.

6. On the **Connect your directories** page, 選択します **Next**.

7. On the **Domain and OU filtering** page, ensure that **Sync 選択しますed domains and OUs** is 選択しますed and then expand **Contoso.com**.

8. Select the check box next to **Entra ID clients**. **Do not make any other changes** and then 選択します **Next**.

9. In the **Optional features** page, do not make any changes and then 選択します **Next**.

10. In the **Ready to configure** window, 選択します **Configure** to run the configuration and start synchronization.

11. When the configuration is complete, 選択します **Exit**.

    > **Note**: Entra Connect Sync synchronizes automatically now when you modify the OUs being synced. You can use the **Synchronization Service** to monitor sync status.

### タスク 4: Entra ハイブリッド参加を確認する

1. Switch to **SEA-CL2**.

2. Right-click **Start**, 選択します **Shut down or サインアウトします**, and then 選択します **Restart**.

    _注: The reboot will trigger the Entra hybrid join on SEA-CL2._
   
3. After **SEA-CL2** has restarted, 次のユーザーとしてサインインします: **Contoso\\Administrator** パスワード of **Pa55w.rd**.
    
4. タスク バーで, right-click **Start** and 選択します **Windows Terminal (Admin)**.

5. In the **Windows PowerShell** window, 次を入力します command, 続いて **Enter** キーを押します:

   ```powershell
   dsregcmd /status
   ```

6. In the output under **Device State**, 次を確認します: **AzureAdJoined : YES** and **DomainJoined : YES** are displayed.

   > **Note**: If the device is not yet joined to Entra ID, switch back to **SEA-SRV1** and run the command below. Once completed, switch back to SEA-CL2 and restart the computer once more.
   
   ```powershell
   Start-ADSyncSyncCycle -PolicyType Delta
   ```

7. Close all windows on SEA-CL2 and サインアウトします.

8. Switch to **SEA-SVR1** and switch to the Microsoft Entra admin center.

9. Select **Devices** > **All devices**. 

10. Verify that **SEA-CL2** has **Microsoft Entra hybrid joined** as value for the row **Join Type**. If necessary, 選択します the **Refresh** button if SEA-CL2 is not listed.

11. Close all windows on **SEA-SVR1**.

**結果**: After completing this exercise, you will have successfully configured and validated Entra hybrid join.
